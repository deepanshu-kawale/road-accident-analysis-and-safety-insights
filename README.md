# road-accident-analysis-and-safety-insights
End-to-End Road Accident Analysis using Excel, SQL, Python and Power BI

🚦 Road Accident Analysis & Safety Insights
📌 Overview

This project focuses on analyzing road accident data to identify key patterns, trends, and risk factors influencing road safety. The goal is to derive actionable insights that can help reduce accidents and improve traffic management using data-driven decisions.

📊 Problem Statement

Road accidents are a major public safety issue causing loss of life and property. It is difficult to identify accident-prone locations, peak accident times, and contributing factors such as weather and road conditions. This project analyzes accident data to uncover patterns and support better decision-making for road safety improvements.

🗃️ Dataset Information
Source: Kaggle dataset
Initial size: ~2,00,000 records & 47 columns
After cleaning: 199,320 rows & 21 columns
Data cleaning included removal of irrelevant columns and handling missing values

🛠️ Tools & Technologies Used
Excel – Data cleaning, duplicate removal, missing value handling
SQL – Data querying, joins, grouping, aggregation
Python (Pandas, Matplotlib, Seaborn) – Data analysis and visualization
Power BI – Interactive dashboards and data visualization

🔍 Key Analysis Performed
Cities with highest accident counts
State-wise accident severity analysis
Weather impact on accident frequency and severity
Time-based (hour-wise) accident trends
Road feature analysis during rush hours
Geographic hotspot analysis using latitude & longitude

📈 Key Insights
Certain cities and states consistently report higher accident rates
Accidents are more frequent during peak traffic hours
Poor weather conditions significantly increase accident risk
Junctions, crossings, and traffic signals are high-risk zones
Low visibility and high humidity conditions contribute to severe accidents

💡 Proposed Solutions
Improve traffic monitoring in high-risk cities
Implement weather-based alert systems
Enhance road infrastructure at junctions and crossings
Increase surveillance during peak accident hours
Use warning systems in low visibility and high-risk zones
Strengthen road safety regulations and speed control systems

📌 Conclusion

The analysis shows that road accidents are strongly influenced by time, weather, and infrastructure conditions. Targeted safety measures in high-risk areas and improved traffic management can significantly reduce accident frequency and severity.
